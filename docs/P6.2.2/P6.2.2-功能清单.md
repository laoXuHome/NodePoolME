# P6.2.2 功能清单

- 版本：v2.047
- 页面：`/#/unified-subscription`
- 定位：后台统一订阅预览与管理员下载，不开放正式客户端订阅入口

## 一、统一节点集合

- [x] 读取当前 P6.1 六类最终优选。
- [x] 六类取并集，按稳定 `node_id` 去重。
- [x] 同节点跨类合并类别与业务资格。
- [x] 同名不同 ID 不合并。
- [x] 不固定数量、不补位。
- [x] 六类全空时生成有效空订阅并标记 `empty`。
- [x] 不修改 P5 竞争状态和 P6.1 快照。

## 二、业务标签与命名

- [x] `gpt→GPT`、`youtube→YT`、`telegram→TG`、`github→GH`。
- [x] `standard/global` 不产生标签。
- [x] 标签顺序固定 `GPT→YT→TG→GH`。
- [x] 多标签去重合并。
- [x] 保留速度 emoji、机场名、原始节点名。
- [x] 无标签不生成空段。
- [x] 不改 P6.1 原始节点名。
- [x] 最终重名只加 ` #2` 序号，四格式共用。
- [x] 重复后缀在 Base64 URI 片段中正确转义。

## 三、关键词过滤

- [x] 只消费 P6.2.1 当前预览，不重复实现匹配。
- [x] 强制绑定当前 P6.1 `version_id`。
- [x] 强制绑定当前 `rule_revision`。
- [x] 缺结果、版本或修订不一致时禁止生成。
- [x] 同节点跨类命中原因取并集。
- [x] 命中节点不进入四格式内容。
- [x] 命中节点仍在管理预览保留标签与原因。
- [x] 过滤不撤销 P5/P6.1 资格。

## 四、四种格式

- [x] Clash / Mihomo YAML。
- [x] sing-box JSON。
- [x] 通用 Base64 URI 列表。
- [x] Loon 文本。
- [x] 四格式共用同一集合、顺序、展示名、数量。
- [x] 格式兼容性预检，不支持节点统一排除并记录原因。
- [x] 格式独立构建、独立校验、独立状态。
- [x] 失败写真实原因，批次 `partial/failed`，不伪造成功。
- [x] 下载文件名、媒体类型、批次数/节点数响应头。
- [x] 不输出机场原始 URL、Token、上游凭据或内部管理字段。

## 五、版本与历史

- [x] `np622_batches` / `np622_outputs` / `np622_nodes` / `np622_events`。
- [x] 每批固定四种格式。
- [x] 批次号 `P6.2.2-0001` 递增。
- [x] 记录 P6.1 版本 ID/版本号、P6.2.1 修订号/重算时间。
- [x] 记录六类数量、合并/去重/过滤/候选/排除/输出数量。
- [x] 记录 GPT/YT/TG/GH/多标签数量。
- [x] 记录格式 SHA256、字节、失败原因。
- [x] 历史只追加，不覆盖、不删除。
- [x] 重复生成创建新批次，不创建 P6.1 版本。
- [x] 版本/规则变化后旧批次标记 `stale`，下载 409。

## 六、页面

- [x] 统一概况：状态、P6.1 版本、规则修订、四联数量、批次、SHA。
- [x] 六类合并卡及合并等式。
- [x] 标签统计：GPT/YT/TG/GH/多标签。
- [x] 格式 tab、内容预览、数量、时间、版本、SHA。
- [x] 管理员下载按钮。
- [x] 手动重新生成按钮。
- [x] 节点预览含允许、过滤、不兼容状态。
- [x] 被过滤节点可显示/隐藏。
- [x] 批次生成记录。
- [x] 桌面与 390px 移动适配。
- [x] 菜单第 11 项“统一订阅”，总菜单 14 项。

## 七、Dashboard
