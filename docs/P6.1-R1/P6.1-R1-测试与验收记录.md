## 二、专项测试

命令：

```bash
python -m pytest tests/test_final_p6.py -q
```

结果：`12 passed in 43.57s`。

测试项：

| 编号 | 测试 | 验证点 |
|---|---|---|
| 1 | 六类优选与跨类节点 | 六类独立生成，同一节点可进入全部类别 |
| 2 | 新增/移除/保留与历史不可变 | 类别隔离、旧版本生成后内容不变、重复读取不建版本 |
| 3 | 有效空版本 | P5 成功且无优选时生成 `is_empty=1`，不继承旧节点 |
| 4 | 无效轮次保护 | 无 P5 run、`running`、`partial` 均拒绝，不覆盖有效版本 |
| 5 | P1/P5 不变 | 快照前后 `np5_state`、`np5_history`、`np5_runs` 一致 |
| 6 | 真实存储与 Dashboard | 摘要、版本、Dashboard 计数来自真实表 |
| 7 | 改名 | 同一 `node_id` 改名生成新版本 |
| 8 | 换服务器 | 同一 `node_id` 换 server 生成新版本 |
| 9 | 换端口 | 同一 `node_id` 换 port 生成新版本 |
| 10 | 机场改名 | 同一节点换机场显示名生成新版本 |
| 11 | 换机场 ID | 同一节点换机场 ID 生成新版本 |
| 12 | 旧签名兼容 | v2.044 仅成员签名在身份无变化时不产生重复版本 |

### 身份变化专项断言

- `created=True`，`previous_version_id` 指向旧版本；
- 差异中 `added=[]`、`removed=[]`、`retained=[node_id]`；
- `retained.changed_fields` 包含预期字段；
- `retained.before` 与 `retained.after` 均保留同一 `node_id`；
- 旧版本详情仍为原始名称、地址、端口、机场；
- 新版本当前详情为变化后的值；
- 改完后再连续快照 3 次均 `unchanged`，历史版本数保持 2。
