## 八、边界与已知观察

1. 订阅格式预览接口返回本批真实订阅内容，因此包含客户端连接所需的密码、UUID 等参数。任务只禁止普通列表、Dashboard 和日志明文展示，未要求订阅内容脱敏；普通视图已确认不含参数。
2. v2.047 旧批次迁移后快照字段为空，统一标记 `config_snapshot_missing` 并 stale，需要重新生成；历史内容仍可追溯。
3. 当前生成遇到 P1 缺少稳定 ID 的连接配置时直接阻断，错误为 `node_config_missing`；普通概况读取仍可展示缺失并派生 stale。
4. 四格式生成仍共用同一 `output_nodes` 冻结对象，不按格式重新读取 P1，避免同批格式间配置漂移。
